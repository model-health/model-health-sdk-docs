# Activity Analysis

Once an activity has been recorded and processed, you can run an analysis to extract meaningful metrics—provided a built-in analysis module is available for that activity.

## Available Analysis Types

The SDK currently supports 12 analysis types:

- **Overground walking**: Straight walking, no turns
- **Treadmill walking**: Walking on a treadmill
- **Overground running**: Straight running, no turns
- **Treadmill running**: Running on a treadmill
- **Counter movement jump**: Single or double leg, 1+ repetitions
- **Drop vertical jump**: Single or double leg, 1+ repetitions
- **Hop**: Single, double, or triple (crossover)
- **Squat**: Single or double leg, 1+ repetitions
- **505 test**: Agility test involving a 180° turn
- **Cut**: Change of direction (eg, 45° and 90° cuts)
- **Range of motion (ROM) assessment**: ROM measured throughout the trial (activity-independent)
- **Sit-to-stand transfer**: 1+ repetitions

## Starting Analysis

There are two ways to run an analysis:

- **Manually** — call `startAnalysis` after the activity reaches `.ready` status, as shown below.
- **Automatically** — pass an `ActivityConfig` with an activity type when calling `startRecording`. Analysis starts automatically once processing completes and the activity status becomes `.analyzing`. See [Activity Recording](./activity-recording#recording-with-automatic-analysis).

### Manual Analysis

  <TabItem value="swift" label="Swift">

  let status = try await client.activityStatus(for: activity)

## Monitoring Analysis Progress

Analysis should take less than 30 seconds to complete. Poll the status:

<Tabs groupId="language">
  <TabItem value="swift" label="Swift">
  ```swift
  var analysisStatus = try await client.analysisStatus(for: task)

  while case .processing = analysisStatus {
      print("Analysis in progress...")
      try await Task.sleep(nanoseconds: 10_000_000_000) // 10 seconds
      analysisStatus = try await client.analysisStatus(for: task)
  }

  switch analysisStatus {
  case .completed:
      print("Analysis complete!")
  case .failed:
      print("Analysis failed")
  default:
      break
  }
  ```
  </TabItem>
  <TabItem value="ts" label="TypeScript">
  ```typescript
  let analysisStatus = await client.analysisStatus(task);

  while (analysisStatus.type === "processing") {
    console.log("Analysis in progress...");
    await new Promise(resolve => setTimeout(resolve, 10000));
    analysisStatus = await client.analysisStatus(task);
  }

  if (analysisStatus.type === "completed") {
    console.log("Analysis complete!");
  } else if (analysisStatus.type === "failed") {
    console.log("Analysis failed");
  }
  ```
  </TabItem>
  <TabItem value="python" label="Python">
  ```python
  import time
  from modelhealth import AnalysisStatus

  status = client.analysis_status(task)

  while status == AnalysisStatus.processing:
      print("Analysis in progress...")
      time.sleep(10)
      status = client.analysis_status(task)

  if status == AnalysisStatus.completed:
      print("Analysis complete!")
  elif status == AnalysisStatus.failed:
      print("Analysis failed")
  ```

## Downloading Results

Results can be downloaded once an activity has finished processing. `hasResults` (`has_results` in Python) tells you whether it has. It reflects the activity as it was last read, so read the activity again — for example with `refresh()` — to see whether that has changed.

<Tabs groupId="language">
  <TabItem value="swift" label="Swift">
  ```swift
  let current = try await activity.refresh()
  guard current.hasResults else {
      print("Still processing")
      return
  }
  ```
  </TabItem>
  <TabItem value="ts" label="TypeScript">
  ```typescript
  const current = await activity.refresh();
  if (!current.hasResults) {
    console.log("Still processing");
    return;
  }
  ```
  </TabItem>
  <TabItem value="python" label="Python">
  ```python
  current = activity.refresh()
  if not current.has_results:
      print("Still processing")
  ```
  </TabItem>
</Tabs>

You choose which results to download — see [Result Types](#result-types). Each one is downloaded on its own, so a result that is missing does not stop the others from arriving.

### Fetching into Memory

  <TabItem value="swift" label="Swift">
  ```swift
  let fetched = try await client.fetchArtifacts([.metrics, .report], for: activity)

  if let report = fetched.data[.report] {
      print("Report: \(report.count) bytes")
  }
  for (result, error) in fetched.errors {
      print("\(result.rawValue) not downloaded: \(error)")
  }
  ```
  </TabItem>
  <TabItem value="ts" label="TypeScript">
  ```typescript
  const fetched = await client.fetchArtifacts(activity, ["metrics", "report"]);

  const report = fetched.data.report; // Uint8Array
  if (report) {
    console.log(`Report: ${report.length} bytes`);
  }
  for (const [result, error] of Object.entries(fetched.errors)) {
    console.log(`${result} not downloaded: ${error.message}`);
  }
  ```
  </TabItem>
  <TabItem value="python" label="Python">
  ```python
  from modelhealth import ArtifactType

  fetched = client.fetch_artifacts(activity, [ArtifactType.metrics, ArtifactType.report])

  report = fetched.data.get(ArtifactType.report)  # bytes
  if report:
      print(f"Report: {len(report)} bytes")
  for result, error in fetched.errors.items():
      print(f"{result} not downloaded: {error}")
  ```
  </TabItem>
</Tabs>

Every result you ask for ends up in exactly one place: its bytes in `data`, or the reason it could not be downloaded in `errors`. A result the activity does not have — for example a report for an activity that was never analyzed — is reported as `notAvailable` in Swift and `NotAvailableError` in TypeScript and Python. Its message says whether it may still appear later, for instance once a running analysis finishes, or not.

### Saving to Files

In Swift and Python, `downloadActivity` (`download_activity`) saves each result as a file in the directory you give it, creating the directory if needed:

<Tabs groupId="language">
  <TabItem value="swift" label="Swift">
  ```swift
  let directory = URL(fileURLWithPath: "results")
  let saved = try await client.downloadActivity(
      activity,
      to: directory,
      artifacts: ArtifactType.allCases
  )

  for (result, file) in saved.paths {
      print("\(result.rawValue): \(file.path)")
  }
  for (result, error) in saved.errors {
      print("\(result.rawValue) not saved: \(error)")
  }
  ```
  </TabItem>
  <TabItem value="ts" label="TypeScript">
  ```typescript
  // Node.js: TypeScript has no downloadActivity, so write the fetched bytes yourself.
  // artifactFileName gives each file the same name the other SDKs use.
  import { mkdir, writeFile } from "node:fs/promises";
  import { join } from "node:path";
  import type { ArtifactType } from "@modelhealth/modelhealth";

  const fetched = await client.fetchArtifacts(
    activity,
    ["metrics", "report", "data", "kinematics_csv"]
  );

  await mkdir("results", { recursive: true });
  for (const [result, bytes] of Object.entries(fetched.data)) {
    const name = client.artifactFileName(activity, result as ArtifactType);
    await writeFile(join("results", name), bytes);
  }
  ```
  </TabItem>
  <TabItem value="python" label="Python">
  ```python
  saved = client.download_activity(activity, "results", list(ArtifactType))

  for result, path in saved.paths.items():
      print(f"{result}: {path}")
  for result, error in saved.errors.items():
      print(f"{result} not saved: {error}")
  ```
  </TabItem>
</Tabs>

Files are named `<stem>_metrics.json`, `<stem>_report.pdf`, `<stem>_data.zip` and `<stem>_kinematics.csv`, the same in every SDK. By default the stem is the activity's name followed by the start of its id, so two activities with the same name do not overwrite each other. Pass `stem` to choose your own.

### Reading the Metrics

The metrics file is JSON. Metrics are organized into groups, the same way they appear on the dashboard. Each metric has a single value, or a left and a right value:

```json
{
  "groups": [
    {
      "name": "Group name",
      "description": "What this group measures",
      "metrics": [
        { "name": "A single value", "description": "...", "value": { "type": "scalar", "value": 32.4 } },
        { "name": "A value per side", "description": "...", "value": { "type": "bilateral", "left": 81.2, "right": 79.5 } }
      ]
    }
  ]
}
```

## Result Types

| Result | Swift | TypeScript | Python | Format | Contents |
|---|---|---|---|---|---|
| Metrics | `.metrics` | `"metrics"` | `ArtifactType.metrics` | JSON | The activity's metrics, grouped as on the dashboard |
| Report | `.report` | `"report"` | `ArtifactType.report` | PDF | The analysis report |
| Data | `.data` | `"data"` | `ArtifactType.data` | ZIP | CSV files with joint angles and positions, angular velocities and speeds, and the extended metrics list |
| Kinematics | `.kinematicsCsv` | `"kinematics_csv"` | `ArtifactType.kinematics_csv` | CSV | Joint angles over time |

## Complete Example

Here's a complete workflow from recording to analysis:

<Tabs groupId="language">
  <TabItem value="swift" label="Swift">
  ```swift
  // Record
  let activity = try await client.startRecording(activityNamed: "cmj", in: session)
  // ... subject performs jump ...
  try await client.stopRecording(session)

  // Wait for processing
  var activityStatus = try await client.activityStatus(for: activity)
  while case .processing = activityStatus {
      try await Task.sleep(nanoseconds: 10_000_000_000)
      activityStatus = try await client.activityStatus(for: activity)
  }

  // Start analysis
  guard case .ready = activityStatus else {
      print("Activity failed processing")
      return
  }

  let task = try await client.startAnalysis(.counterMovementJump, for: activity, in: session)

  // Wait for analysis
  var analysisStatus = try await client.analysisStatus(for: task)
  while case .processing = analysisStatus {
      try await Task.sleep(nanoseconds: 10_000_000_000)
      analysisStatus = try await client.analysisStatus(for: task)
  }

  // Download results
  if case .completed = analysisStatus {
      let fetched = try await client.fetchArtifacts([.metrics], for: activity)
      if let raw = fetched.data[.metrics],
         let json = try JSONSerialization.jsonObject(with: raw) as? [String: Any],
         let groups = json["groups"] as? [[String: Any]] {
          for group in groups {
              for metric in group["metrics"] as? [[String: Any]] ?? [] {
                  print(metric["name"] ?? "", metric["value"] ?? "")
              }
          }
      }
  }
  ```
  </TabItem>
  <TabItem value="ts" label="TypeScript">
  ```typescript
  // Record
  const activity = await client.startRecording("cmj", session);
  // ... subject performs jump ...
  await client.stopRecording(session);

  // Wait for processing
  let activityStatus = await client.activityStatus(activity);
  while (activityStatus.type === "processing" || activityStatus.type === "uploading") {
    await new Promise(resolve => setTimeout(resolve, 10000));
    activityStatus = await client.activityStatus(activity);
  }

  // Start analysis
  if (activityStatus.type !== "ready") {
    console.log("Activity failed processing");
    return;
  }

  const task = await client.startAnalysis("counter_movement_jump", activity, session);

  // Wait for analysis
  let analysisStatus = await client.analysisStatus(task);
  while (analysisStatus.type === "processing") {
    await new Promise(resolve => setTimeout(resolve, 10000));
    analysisStatus = await client.analysisStatus(task);
  }

  // Download results
  if (analysisStatus.type === "completed") {
    const fetched = await client.fetchArtifacts(activity, ["metrics"]);
    const raw = fetched.data.metrics;
    if (raw) {
      const { groups } = JSON.parse(new TextDecoder().decode(raw));
      for (const group of groups) {
        for (const metric of group.metrics) {
          console.log(`${metric.name}:`, metric.value);
        }
      }
    }
  }
  ```
  </TabItem>
  <TabItem value="python" label="Python">
  ```python
  import json
  import time
  from modelhealth import ModelHealthClient, ActivityStatus, ActivityStatusUploading, AnalysisStatus, ArtifactType

  client = ModelHealthClient("your-api-key-here")

  # Select a session and activity
  session = client.session_list()[0]
  activity = client.activity_list(session)[0]

  # Wait for processing
  activity_status = client.activity_status(activity)
  while isinstance(activity_status, ActivityStatusUploading) or activity_status == ActivityStatus.processing:
      time.sleep(10)
      activity_status = client.activity_status(activity)

  if activity_status != ActivityStatus.ready:
      print("Activity failed processing")
  else:
      # Start analysis
      task = client.start_analysis("counter_movement_jump", activity, session)

      # Wait for analysis
      analysis_status = client.analysis_status(task)
      while analysis_status == AnalysisStatus.processing:
          time.sleep(10)
          analysis_status = client.analysis_status(task)

      # Download results
      if analysis_status == AnalysisStatus.completed:
          fetched = client.fetch_artifacts(activity, [ArtifactType.metrics])
          raw = fetched.data.get(ArtifactType.metrics)
          if raw:
              for group in json.loads(raw)["groups"]:
                  for metric in group["metrics"]:
                      print(f"  {metric['name']}:", metric["value"])
  ```

## Error Handling

Always handle potential errors during analysis:

<Tabs groupId="language">
  <TabItem value="swift" label="Swift">
  ```swift
  do {
      let task = try await client.startAnalysis(.counterMovementJump, for: activity, in: session)
      // Monitor and download results...
  } catch {
      print("Analysis error: \(error)")
      // Handle error appropriately
  }
  ```
  </TabItem>
  <TabItem value="ts" label="TypeScript">
  ```typescript
  try {
    const task = await client.startAnalysis("counter_movement_jump", activity, session);
    // Monitor and download results...
  } catch (error) {
    console.error("Analysis error:", error);
    // Handle error appropriately
  }
  ```
  </TabItem>
  <TabItem value="python" label="Python">
  ```python
  from modelhealth import ModelHealthError

  try:
      task = client.start_analysis("counter_movement_jump", activity, session)

  except ModelHealthError as e:
      print(f"Analysis error: {e}")
      # Handle error appropriately
  ```
