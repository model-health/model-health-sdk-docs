    Interface Activity

    A movement recording trial with associated videos and results.

    Activities represent individual recording trials and contain references to captured videos and results.

    Example

    const activities = await client.activityList(session.id);
    for (const activity of activities) {
      console.log(`${activity.name ?? activity.id}: ${activity.status}`);
    }

    OptionalactivityType

    activityType?: ActivityTypeInfo

    The activity type as reported, if one was set.

    Carries {id, name, displayName} through unchanged — including a type this SDK build doesn't recognize.

    OptionalanalysisStatus

    analysisStatus?: string

    State of the analysis pipeline: "processing", "done", "error", or undefined when this activity was not loaded through a path that reports it (for example, nested inside a session).

    OptionalcoreEngine

    coreEngine?: string

    Core engine version for this activity, as the server stores it (e.g. "v2.0"), or undefined when it uses the session's setting.

    createdAt

    createdAt: Date

    When this activity was created.

    OptionalcreatedBy

    createdBy?: string

    Username of the account that owns the parent session, if known.

    OptionalfilterFrequency

    filterFrequency?: string

    Low-pass filter frequency for this activity, as the server stores it ("default" or a value in Hz such as "12"), or undefined when it uses the session's setting.

    Optionalframerate

    framerate?: string

    Frame rate this activity was recorded at, as the server stores it (e.g. "120"), or undefined when it uses the session's setting.

    sessionId: string

    status

    status: string

    OptionalsubjectInfo

    subjectInfo?: ActivitySubject

    A summary of the subject the activity was recorded for, if it has one.

    Lets a list that spans several subjects tell whose activity each row is. Reading it costs nothing; for the subject itself, read on first access, see Activity.subject. undefined for an activity whose session has no subject, and for one loaded through a path that does not report it (for example, nested inside a session).
